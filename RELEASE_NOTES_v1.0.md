# π1 Elvira I&II VGA Editor v1.0

Initial public release of **π1 Elvira I&II VGA Editor**.

A Windows editor for working with graphics and text resources from **Elvira: Mistress of the Dark** and **Elvira II: The Jaws of Cerberus**.

## Features

- Support for Elvira I and Elvira II
- VGA resource detection and parsing
- Sprite and image preview
- Multiple VGA palettes
- Pixel-perfect preview
- Adjustable image zoom
- PNG export
- PNG replacement
- Safe application of modified graphics to game files
- Automatic backup handling
- GAMEPC text editor
- Text resource editing and saving
- Slovak, Czech and English user interface
- Windows x64 self-contained build

## Installation

1. Download `Pi1-Elvira-I-II-VGA-Editor-v1.0-win-x64.zip`.
2. Extract the archive.
3. Run `Pi1ElviraVgaEditor.exe`.
4. Select your Elvira I or Elvira II game directory.

No separate .NET installation is required.

## Important

This project does **not** contain or distribute original Elvira game data, graphics, text resources or other copyrighted game assets.

You must provide your own legally obtained copy of the game.






Always keep a backup of your original game files before modifying them.
